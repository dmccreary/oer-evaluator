# Practice and Feedback

## Summary

Covers the practice metric: worked examples, formative assessment, quizzes, question quality, immediate feedback, retrieval practice, and interactive simulations that let learners try and check their understanding. It completes the quality metrics by asking whether learners can practice and get feedback. After this chapter you can judge quizzes and worked examples, and decide when an interactive simulation would help a learner more than text.
