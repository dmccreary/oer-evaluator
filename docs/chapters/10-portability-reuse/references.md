# References: Portability and Reuse Across Platforms

1. [Learning management system](https://en.wikipedia.org/wiki/Learning_management_system) - Wikipedia - Describes what learning management systems do, the major products, and how course content is delivered through them. Background for testing whether a resource can be imported into an LMS.

2. [Vendor lock-in](https://en.wikipedia.org/wiki/Vendor_lock-in) - Wikipedia - Explains how dependence on one vendor's format or platform makes switching costly. Supports the chapter's discussion of platform lock-in and why it lowers a portability score.

3. [Learning Tools Interoperability](https://en.wikipedia.org/wiki/Learning_Tools_Interoperability) - Wikipedia - Describes the standard that lets external learning tools plug into an LMS. Shows one way a resource can be embedded across platforms without being copied.

4. Responsive Web Design - Ethan Marcotte - A Book Apart (2011) - Marcotte coined the term and showed how fluid grids, flexible images, and media queries let one page serve any screen. It explains why a portable resource needs no separate version for each device.

5. Resilient Web Design - Jeremy Keith - Self-published, free online (2016) - Keith argues for starting with content that works everywhere and enhancing from there. That layered approach keeps a resource usable on old browsers and weak connections, which the portability metric tests.

6. [Common Cartridge](https://www.1edtech.org/standards/cc) - 1EdTech - The official page for Common Cartridge, the open package format that lets learning management systems import and exchange course content. The standard behind the chapter's LMS import test.

7. [Learning Tools Interoperability (LTI)](https://www.1edtech.org/standards/lti) - 1EdTech - The official page for the LTI standard, which connects external tools to learning platforms. Useful for understanding how an interactive resource can be launched from many systems.

8. [<iframe>: The Inline Frame Element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe) - MDN Web Docs - Reference for the HTML element that embeds one page inside another, including attributes and security notes. Directly supports the chapter's iframe embedding test.

9. [Can I use](https://caniuse.com/) - Can I use - Browser support tables for web features across current and older browsers. Lets a reviewer check whether the features a resource relies on work in the main browsers.

10. [Learn Responsive Design](https://web.dev/learn/design/) - web.dev - A free course on building pages that adapt to different screens and settings. Helps teachers recognize the design choices that make content reach every learner and device.
