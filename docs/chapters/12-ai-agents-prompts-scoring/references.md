# References: AI Agents, Prompts, and Rubric Scoring

1. [Large language model](https://en.wikipedia.org/wiki/Large_language_model) - Wikipedia - Explains how large language models are trained, how they use tokens and context, and what they can and cannot do. Background for the chapter's sections on models and the context window.

2. [Prompt engineering](https://en.wikipedia.org/wiki/Prompt_engineering) - Wikipedia - Surveys techniques such as few-shot examples and chain-of-thought prompting for steering a model's output. Supports the chapter's guidance on writing prompts and prompt templates.

3. [Intelligent agent](https://en.wikipedia.org/wiki/Intelligent_agent) - Wikipedia - Defines an agent as a system that perceives its environment and acts toward goals, with common agent types. The foundation for the chapter's distinction between an assistant and an agent.

4. Artificial Intelligence: A Modern Approach (4th ed.) - Stuart Russell and Peter Norvig - Pearson (2020) - Russell and Norvig organize the whole field around the rational agent and describe tasks with PEAS: performance measure, environment, actuators, and sensors. This gives a precise vocabulary for what an agent is.

5. Hands-On Large Language Models - Jay Alammar and Maarten Grootendorst - O'Reilly (2024) - Alammar, known for his illustrated explainers, uses diagrams to show how language models handle tokens, context, and prompts without heavy mathematics. A readable base for the chapter's model and prompt concepts.

6. [Building Effective AI Agents](https://www.anthropic.com/research/building-effective-agents) - Anthropic - Separates workflows from agents and describes patterns such as prompt chaining, routing, and evaluator-optimizer. Helps teachers understand the agent workflow this chapter uses for rubric scoring.

7. [Prompt Engineering Overview](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview) - Claude Platform Docs - Official guidance on writing clear prompts, giving examples, and iterating with tests. Supports the chapter's section on prompt iteration, where a rubric prompt is refined after checking the agent's first results.

8. [Agent Skills Overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) - Claude Platform Docs - Explains skills as packaged instructions and resources that an agent loads when relevant. Shows the format behind the reusable evaluator skills this book teaches readers to build.

9. [Prompt Engineering Guide](https://www.promptingguide.ai/) - DAIR.AI - A free catalog of prompting techniques with examples, including zero-shot, few-shot, and chain-of-thought prompts. A handy reference while building a rubric prompt.

10. [Transformers, the Tech Behind LLMs](https://www.3blue1brown.com/lessons/gpt) - 3Blue1Brown - A visual explanation of how a language model turns text into predictions, with animated diagrams. Builds intuition for why a model can sound sure and still be wrong.
