# References: Open File Formats and Version Control

1. [Open file format](https://en.wikipedia.org/wiki/Open_format) - Wikipedia - Defines file formats whose specifications are published so anyone can implement them without fees, with examples. Background for deciding whether a resource's source files count as open and editable.

2. [Markdown](https://en.wikipedia.org/wiki/Markdown) - Wikipedia - Describes the lightweight plain-text syntax, its history, and variants such as CommonMark. Shows why Markdown is this book's recommended editable source format for text.

3. [Git](https://en.wikipedia.org/wiki/Git) - Wikipedia - Explains Git's distributed model, commits, branches, and history. Background for the chapter's version control section and for reading repository history as evidence when scoring editable source.

4. Pro Git (2nd ed.) - Scott Chacon and Ben Straub - Apress (2014) - Chacon and Straub explain Git as a series of snapshots of the whole project rather than a list of file differences. That mental model, with clear diagrams of commits and branches, makes history easy to picture.

5. Version Control by Example - Eric Sink - Pyrenean Gold Press (2011) - Sink walks two fictional developers through parallel edits and merges, repeating the story in centralized and distributed tools. The approach helps nonprogrammers see why a shared history matters.

6. [Markdown Guide: Basic Syntax](https://www.markdownguide.org/basic-syntax/) - Markdown Guide - A clear reference for headings, emphasis, lists, links, and images in Markdown, with side-by-side examples. Enough to read and edit the Markdown source of an OER and to try the chapter's exercises.

7. [CommonMark Help](https://commonmark.org/help/) - CommonMark - A quick Markdown reference plus an interactive ten-minute tutorial built on the CommonMark standard. Lets teachers practice the syntax in the browser before editing a resource.

8. [Hello World](https://docs.github.com/en/get-started/using-github/hello-world) - GitHub Docs - A short tutorial that creates a repository, a branch, a commit, and a pull request. Gives teachers hands-on experience with the version control steps this chapter describes.

9. [Version Control with Git](https://swcarpentry.github.io/git-novice/) - Software Carpentry - A free lesson for beginners on tracking changes, viewing history, and collaborating with Git, written for people who are not programmers. A gentle companion to the chapter's version control section.

10. [Basic HTML Syntax](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax) - MDN Web Docs - Introduces elements, tags, and attributes in HTML. Helps teachers recognize HTML as an open, editable source format and read the pages they will adapt.
