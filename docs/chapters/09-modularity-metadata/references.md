# References: Modularity and Metadata

1. [Dublin Core](https://en.wikipedia.org/wiki/Dublin_Core) - Wikipedia - Describes the fifteen-element Dublin Core metadata set, its history, and its use in libraries and repositories. The basis of the metadata record taught in this chapter.

2. [Metadata](https://en.wikipedia.org/wiki/Metadata) - Wikipedia - Surveys kinds of metadata, standards, and uses, from library catalogs to web pages. Background for scoring whether a resource carries complete, useful metadata.

3. [Learning object](https://en.wikipedia.org/wiki/Learning_object) - Wikipedia - Explains the learning object idea of small, self-contained, reusable units of instruction and the standards built around it. Supports the chapter's modularity metric.

4. The Instructional Use of Learning Objects - David A. Wiley (ed.) - Agency for Instructional Technology and AECT (2002) - Wiley's writing on learning objects popularized the LEGO-block metaphor for small reusable pieces and argued that pieces do not combine at random. That is why a module must stand alone yet fit its neighbors.

5. Metadata - Jeffrey Pomerantz - MIT Press (2015) - No single signature analogy stands out for this topic, so this is the short introduction most praised for making metadata clear to non-specialists. It explains standards, schemas, and uses in plain language.

6. [Metadata Basics](https://www.dublincore.org/resources/metadata-basics/) - Dublin Core Metadata Initiative - The DCMI introduction to metadata and the Dublin Core style, listing the fifteen core elements such as title, creator, subject, and description. The primary reference for the chapter's core fields.

7. [DCMI Metadata Terms](https://www.dublincore.org/specifications/dublin-core/dcmi-terms/) - Dublin Core Metadata Initiative - The official definitions of every Dublin Core term. Lets reviewers check exactly what a field such as rights, format, or audience is meant to record.

8. [LearningResource](https://schema.org/LearningResource) - Schema.org - The Schema.org type for educational materials, with properties such as educational level, learning resource type, and what the resource teaches. Shows how machine-readable metadata describes an OER.

9. [Learning Resource Metadata Initiative (LRMI)](https://www.dublincore.org/specifications/lrmi/) - Dublin Core Metadata Initiative - Describes the vocabulary, maintained by DCMI, that adds educational properties such as alignment to standards and typical age range to resource descriptions. Supports scoring education-specific metadata.

10. [Introduction to Metadata](https://www.getty.edu/publications/intrometadata/) - Getty Research Institute - A free online edition of the Getty's guide to metadata types, standards, and crosswalks, with examples from cultural collections. Gives deeper background for writing consistent records.
