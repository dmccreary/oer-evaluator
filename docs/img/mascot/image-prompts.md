# Echo the Loon: Image Prompts

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Each prompt below is self-contained. Paste one prompt at a time into your
image generator. Generate at 1024x1024 pixels, then run the trimmer on each
file (see the end of this page).

The character is defined in [character-sheet.md](character-sheet.md). If you
change the description here, change it there too.

## 1. Neutral (`neutral.png`)

```
Please generate a new pose for Echo the Loon.
A flat cartoon illustration of Echo the Loon, a friendly pedagogical mascot for a textbook about evaluating and improving open educational resources. Echo is a common loon with a glossy near-black head and neck, a white belly, and a black back covered in a white checkered pattern, with the loon's red eye. Echo wears a small indigo scarf and holds a magnifying glass with a burnt-orange handle in one wing. Echo has a calm, sharp-eyed, friendly expression with a small closed-beak smile. The character is small and compact, suitable for icon-sized display.
Style: modern flat vector, clean lines, transparent background with alpha channel, suitable for embedding in educational content. No text in image.

Echo stands upright in a relaxed, neutral pose facing the viewer, with a calm and friendly closed-beak smile. The free wing rests naturally at Echo's side and the magnifying glass is held low. No specific gesture. The pose is balanced and unassuming, suitable as a general-purpose or default illustration.

Please generate a new RGBA PNG image now with a fully transparent alpha-channel background.
The background MUST be fully transparent with an alpha channel. DO NOT use a white, black or a checkered background.
```

## After you generate the images

Save the seven files in `docs/img/mascot/` as `neutral.png`, `welcome.png`, `thinking.png`, `tip.png`, `warning.png`, `encouraging.png`, and `celebration.png`. Each should be an RGBA PNG with a fully transparent background, under 100 KB.

AI image generators often add transparent padding, which makes the mascot look too small. Trim every image from the project root:

```bash
for f in neutral welcome thinking tip warning encouraging celebration; do python "$BK_HOME/src/image-utils/trim-padding-from-image.py" docs/img/mascot/$f.png; done
```
