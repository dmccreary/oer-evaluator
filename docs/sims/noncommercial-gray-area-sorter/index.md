## Description

The NonCommercial element is vague on purpose. Creative Commons defines it as use that is not primarily intended for or directed toward commercial advantage or monetary compensation, and reasonable people disagree about some uses. This MicroSim shows ten uses of a CC BY-NC worksheet. You judge each one against that criterion.

The middle bin, **Unclear: ask the owner**, is a valid answer and not a failure to decide. The bins give a likely reading, not legal advice.

| Bin | Meaning |
|---|---|
| Clearly allowed | No one earns money from the use. |
| Unclear: ask the owner | The use touches money in a way reasonable people disagree about. |
| Likely not allowed | The use earns money or is directed toward earning it. |

### Controls

- **Three bin buttons:** place the use in a bin. The placement is final.
- **Next:** moves to the next use.
- **Show definitions:** on a narrow screen the criterion and bin definitions move behind this button.
- **Previous missed / Next missed** and **Play again** on the results screen.

### Good to Know

Only your first committed answer on the first completed run counts as evidence of mastery. Practice runs give the same feedback but do not change that first-run score. Nothing moves until you act, and the MicroSim does not store your answers.

- The ten uses are illustrative examples written for Chapter 2.
- Only the Clearly allowed bin means no permission is needed.

## Lesson Plan

### Learning Objective

After using this MicroSim, the learner can **judge** whether each of ten uses of a CC BY-NC resource is clearly allowed, unclear, or likely not allowed, with at least 8 of 10 correct on the first attempt. (Bloom level: Evaluate.)

### Grade Level

Adult learners: teachers (K-12 and college), instructional designers, librarians, and OER coordinators.

### Duration

10-15 minutes.

### Prerequisites

- The terms *NonCommercial requirement*, *CC BY-NC*, and *attribution requirement* from [Chapter 2](../../chapters/02-open-licenses-attribution/index.md).

### Activities

1. **Predict (2 min).** Read the criterion. Which of these will be hardest to judge: a paid course, a bookstore sale at cost, or a free class website?
2. **Sort the uses (6 min).** Place all ten uses and read each reason.
3. **Discuss (4 min).** With a partner, pick one Unclear use and write the email you would send the owner to ask permission.
4. **Replay (2 min).** Play again and try to explain each answer aloud before you click.

### Assessment

Ask learners to answer without the MicroSim, then check each answer by using it.

1. A blog with paid ads posts the worksheet. Which bin? *(Likely not allowed. The advertising income makes the use commercial.)*
2. A nonprofit workshop charges $20 to cover room and printing. Which bin? *(Unclear: ask the owner. Cost recovery is not profit but is still payment.)*
3. Is a nonprofit always noncommercial? *(No. Judge the use, not the kind of organization.)*
4. Does "free of charge" settle the question? *(No. Advertising on a free page can still make the use commercial.)*

### Connection to the OER Evaluator rubric

The NonCommercial element lowers a resource on the openness spectrum. [Chapter 9](../../chapters/09-modularity-metadata/index.md) shows how the open license metric scores that.
