## Description

This poster puts the six Creative Commons licenses side by side: CC BY, CC BY-SA, CC BY-NC, CC BY-NC-SA, CC BY-ND, and CC BY-NC-ND. Each panel prints its license name, shows its icons, and carries a small pictogram of its main rule.

In **Explore** mode you hover or click a panel to read its summary and facts. In **Quiz me** mode you read a description and click the panel that matches. The poster is a drawing made for this book (SVG). It is not a photograph and it carries no statistics.

| Panel | Main rule |
|---|---|
| CC BY | Credit is the only condition. |
| CC BY-SA | Credit, and keep adaptations open the same way. |
| CC BY-NC | Credit, and no commercial use. |
| CC BY-NC-SA | Credit, noncommercial, and the same license on adaptations. |
| CC BY-ND | Credit, and share the work unchanged only. |
| CC BY-NC-ND | Credit, noncommercial, unchanged only. |

### Controls

- **Explore and Quiz me buttons:** switch modes. Quiz me starts a new run.
- **The six panels:** hover, focus with the Tab key, or click. In quiz mode a click is your answer.
- **Next:** moves to the next question.
- **Play again:** repeats the quiz as practice.

### Good to Know

Only your first committed answer on the first completed run counts as evidence of mastery. Practice runs give the same feedback but do not change that first-run score. Nothing moves until you act, and the MicroSim does not store your answers.

- Each question has one attempt. Only the first completed run counts as evidence.
- The poster prints only the six license names, so the sim adds no labels over it.

## Lesson Plan

### Learning Objective

After using this MicroSim, the learner can **identify** which of the six Creative Commons licenses matches each of six descriptions, with at least 5 of 6 correct on the first attempt. (Bloom level: Remember.)

### Grade Level

Adult learners: teachers (K-12 and college), instructional designers, librarians, and OER coordinators.

### Duration

5-10 minutes.

### Prerequisites

- The six licenses *CC BY*, *CC BY-SA*, *CC BY-NC*, *CC BY-NC-SA*, *CC BY-ND*, and *CC BY-NC-ND* from [Chapter 2](../../chapters/02-open-licenses-attribution/index.md).

### Activities

1. **Explore (3 min).** Hover over each panel and read the facts. Which two licenses forbid sharing changed versions?
2. **Quiz (4 min).** Press **Quiz me** and answer all six questions.
3. **Compare (3 min).** Pick two panels that differ by one element and say what that element changes.

### Assessment

Ask learners to answer without the MicroSim, then check each answer by using it.

1. Which license allows commercial use but forbids sharing changed versions? *(CC BY-ND.)*
2. Which license puts no condition on the work beyond credit? *(CC BY.)*
3. Which license text does Wikipedia use? *(CC BY-SA.)*
4. Does CC BY-NC allow adaptations? *(Yes, as long as use stays noncommercial.)*

### Connection to the OER Evaluator rubric

Reading a license quickly is part of scoring the open license metric. [Chapter 9](../../chapters/09-modularity-metadata/index.md) shows how the rubric rates a stated license.
