# Sample One-Day Workshop Schedule

This workshop trains teachers to evaluate open educational resources (OER)
for quality and reusability with AI agents, and then to use those agents to
improve an OER they already teach with. Teachers arrive with one OER from
their own subject and leave with an improved, openly licensed component and a
checklist for earning the **Certificate of OER Quality Evaluation Using AI
Agents**.

The day runs 8:30 a.m. to 3:30 p.m. and is designed for about 20 teachers.
Every session uses the [Sample Rubric Worksheet](sample-rubric-worksheet.md).

## Before the Workshop

Each teacher should:

- Choose one OER they already use, such as a textbook chapter, a unit, a quiz,
  or an interactive simulation.
- Bring a laptop with access to an AI agent tool.
- Print or download the [Sample Rubric Worksheet](sample-rubric-worksheet.md).

## Schedule

| Time | Session | What teachers leave with |
| --- | --- | --- |
| 8:30 to 9:00 | **Check-in and setup:** log in to the AI tools and load the OER each teacher brought | A working agent session |
| 9:00 to 9:45 | **Why quality and reusability matter:** the 10 metrics and how each is scored | Rubric card |
| 9:45 to 10:45 | **Calibration:** pairs score a sample OER by hand, then run the agent and compare | Hand and agent scores, with gaps explained |
| 10:45 to 11:00 | Break | |
| 11:00 to 12:00 | **Checking the agent:** spot invented citations, misread licenses, and overconfident scores | A verified evaluation of the sample |
| 12:00 to 12:45 | Lunch | |
| 12:45 to 2:15 | **Improvement challenge:** use agents to raise one component's score by adding alt text, splitting content into reusable modules, writing metadata, generating practice questions, or building a simulation | An improved component and its new score |
| 2:15 to 2:30 | Break | |
| 2:30 to 3:15 | **Peer review and publishing:** swap and re-score each other's work, then publish under a CC BY license | A published, openly licensed component |
| 3:15 to 3:30 | **Next steps:** certificate requirements and exit survey | Certificate checklist |

## After the Workshop

Teachers have 30 days to finish the certificate work described at the end of
the [Sample Rubric Worksheet](sample-rubric-worksheet.md). A reviewer checks
each submission against the rubric before the certificate is issued.

The workshop sits inside a longer program, from building the rubric through
the final report. See the [Grant-Period Timeline](grant-period-timeline.md).
