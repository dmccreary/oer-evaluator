    References: Reusable Components and Publishing OER¶

    1. MkDocs - Wikipedia - Describes MkDocs, a static site generator that builds documentation websites from Markdown files and a single configuration file. The tool behind the chapter's publishing workflow.

    2. Directed acyclic graph - Wikipedia - Explains directed graphs with no cycles and their uses, including ordering tasks by dependency. Background for the learning graph, which orders concepts by what must be learned first.

    3. Concept map - Wikipedia - Describes concept maps, which link labeled ideas to show how they relate, and their use in teaching. A close relative of the learning graph introduced in this chapter.

    4. The Pragmatic Programmer: Your Journey to Mastery (20th Anniversary ed.) - David Thomas and Andrew Hunt - Addison-Wesley (2019) - Hunt and Thomas coined DRY, Don't Repeat Yourself: every piece of knowledge should have one authoritative representation. For OER, one quiz or MicroSim embedded in many pages is the same idea.

    5. Learning, Creating, and Using Knowledge: Concept Maps as Facilitative Tools in Schools and Corporations (2nd ed.) - Joseph D. Novak - Routledge (2010) - Novak developed concept maps at Cornell in the 1970s. He shows how a labeled map of concepts and links reveals what a learner must know first, the idea behind this book's learning graph.

    6. Material for MkDocs: Getting Started - Material for MkDocs - Official instructions for installing and configuring the Material theme used by this book. Supports the chapter's steps for building a textbook site.

    7. Creating a GitHub Pages Site - GitHub Docs - Step-by-step instructions for publishing a site from a repository for free. Supports the chapter's walkthrough of publishing an improved OER.

    8. Building Intelligent Textbooks - Dan McCreary - A guide to building interactive textbooks with AI skills, covering learning graphs, MicroSims, and publishing. Background for the components and learning graph discussed in this chapter.

    9. Semantic Versioning 2.0.0 - semver.org - A simple scheme for numbering releases so users can tell a small fix from a breaking change. Useful for keeping a component library's versions clear.

    10. Zenodo - CERN - An open repository that gives uploaded files a DOI and reports views and downloads. One way to publish an OER permanently and begin tracking its reuse.
