    Quiz: Open Licenses and Attribution¶

    Test your understanding of Creative Commons licenses, license statements, attribution, and license compatibility with these review questions.

    1. What are the three layers that every Creative Commons license provides?¶

    1. A plain-language summary, a court ruling, and a registration record
    2. A Commons Deed, the legal code, and machine-readable code
    3. A license name, a version number, and an author credit
    4. A badge icon, a legal notice, and a copyright symbol
    Show Answer

    The correct answer is B. Every CC license comes in three layers so that people, lawyers, and software can each read it. The Commons Deed is a short plain-language summary, the legal code is the full text a court would read, and the machine-readable code is metadata that lets search tools recognize the license. Options A, C, and D mix in items such as a court ruling, a version number, and a copyright symbol, which are not license layers.

    See: Creative Commons

    2. Which Creative Commons element requires that anyone who shares an adaptation must license it under the same license or a compatible one?¶

    1. Attribution (BY)
    2. ShareAlike (SA)
    3. NonCommercial (NC)
    4. NoDerivatives (ND)
    Show Answer

    The correct answer is B. ShareAlike (SA) keeps improvements open by requiring each adaptation to carry the same license, or one that the license lists as compatible. It applies only when you adapt the work, so sharing an unchanged copy needs only credit. Attribution (A) requires credit, NonCommercial (C) limits commercial use, and NoDerivatives (D) forbids sharing changed versions altogether. People call the ShareAlike approach copyleft.

    3. What does the CC0 dedication do?¶

    1. It grants a license that requires credit to the creator but allows no changed versions
    2. It registers the work with Creative Commons so that every later user must ask permission first
    3. It places a work in the public domain by giving up copyright and related rights as far as the law allows
    4. It lets the creator keep every right while allowing free use in classrooms only
    Show Answer

    The correct answer is C. CC0 1.0 Universal is a Creative Commons tool for placing a work in the public domain. It is not a license with conditions: the creator gives up copyright and related rights as far as the law of their country allows, and where the law does not allow that, CC0 acts as a license with no conditions. Credit is not legally required, though it is good practice. Creators use it for data sets and quiz banks.

    See: CC0 Dedication

    4. What does TASL stand for in the credit-line format that Creative Commons recommends?¶

    1. Title, Author, Source, License
    2. Title, Attribution, Statement, License
    3. Type, Author, Scope, Link
    4. Title, Adaptation, Source, Link
    Show Answer

    The correct answer is A. TASL stands for Title, Author, Source, and License. Writing the four parts in order makes a credit line hard to get wrong: for example, "Watershed Basics" by Maria Lopez, a link to the work, licensed under CC BY 4.0. If you changed the work, add a sentence naming the change, such as "Adapted: reading level lowered." The other options mix in terms that are not part of the format.

    5. A teacher-sharing site marks a worksheet CC BY, but the worksheet's own pages say the uploader copied it from a publisher's book. What is the best conclusion?¶

    1. The marking is worthless, because only an owner can grant a license and the uploader did not hold the rights
    2. The marking is valid, because a license statement always overrides what the original source says
    3. The marking is valid, because the license icon on the site proves the creator's intent
    4. The marking is valid, but only after the uploader adds a version number and a link
    Show Answer

    The correct answer is A. Only an owner can grant a license, and the uploader never held the rights to give away, so the marking carries no weight. This is why you trace a resource to its original creator and follow the license link back to the source. When a statement and its source disagree, the source wins. Icons and markings are easy to copy onto pages that never carried a license.

    6. Why can a CC BY-NC-SA work not be combined with a CC BY-SA work?¶

    1. ShareAlike licenses may never be combined with any other Creative Commons license, whatever its elements
    2. CC BY-NC-SA works are in the public domain, so they cannot be mixed with licensed works of any kind
    3. Only works from the same creator can be combined under a ShareAlike license, so remixes need one author
    4. One requires noncommercial use while the other keeps commercial use possible, so no single license satisfies both
    Show Answer

    The correct answer is D. CC BY-SA requires the combined work to be CC BY-SA, which allows commercial use, while CC BY-NC-SA requires the combined work to be CC BY-NC-SA, which does not. No single license meets both demands, so this is a license conflict. Option A is too broad, because a CC BY work combines with a CC BY-SA work. When you face a conflict, choose a different resource, ask an owner in writing, or keep the works separate.

    7. A teacher adds alt text to the images of a CC BY-ND chapter. What does the NoDerivatives requirement allow her to do with the changed copy?¶

    1. She may not add alt text even to a private copy, because any change is forbidden
    2. She may share the changed copy, but only if she keeps the use noncommercial
    3. She may use the changed copy for her own reading, but she may not share it
    4. She may share the changed copy as long as she credits the original author
    Show Answer

    The correct answer is C. NoDerivatives lets you share the work only as it is. It does not forbid private changes, so she may adjust a copy for her own study, but giving the changed copy to students or colleagues counts as sharing, and the license does not allow that. She can ask the owner for permission to share the improved version, or choose a resource that allows changes. Credit alone (D) does not lift the restriction.

    8. Which statement correctly describes fair use in OER work?¶

    1. It is a Creative Commons license that allows classroom copying of any work, with credit to the author
    2. It guarantees that any educational use of a work is allowed without permission, whatever the amount copied
    3. It lets you share a changed version of a whole textbook as long as you credit the author and keep the use educational
    4. It is a case-by-case defense, not a license, and it does not cover sharing a changed copy of a whole resource
    Show Answer

    The correct answer is D. Fair use is a U.S. legal doctrine that a court weighs case by case, usually after a dispute has begun, using four factors: purpose, nature of the work, amount used, and market effect. It is a defense, not a license, so you cannot know in advance how a court would rule. If a license already covers your use, rely on the license, and keep fair use in reserve for small excerpts.

    9. A teacher combines a chapter licensed CC BY with a chapter licensed CC BY-SA into one unit. Which license may the combined unit carry?¶

    1. CC BY-SA, because the ShareAlike source requires it and CC BY accepts it
    2. CC BY, because the more open license always governs the combined work
    3. CC BY-NC, because mixing two licenses makes the combined work noncommercial
    4. No license, because the two sources conflict and cannot be combined
    Show Answer

    The correct answer is A. The method is to write what each source requires of the combined work, then look for a license that satisfies every requirement. CC BY accepts any of the four licenses in the order CC BY, CC BY-SA, CC BY-NC, CC BY-NC-SA, while CC BY-SA requires CC BY-SA, so CC BY-SA is the only license that meets both. This pair does not conflict. Option B reverses the logic, since the ShareAlike source sets the requirement.

    10. A teacher reviews three uses of a CC BY-NC worksheet: handing it out in a public-school class, posting it on a blog that earns paid advertising income, and using it in a $20 nonprofit workshop that charges to cover room and printing costs. Which reading matches the chapter's guidance?¶

    1. All three are allowed, because none of the uses sells the worksheet itself for profit to a customer
    2. Only the class handout is allowed, because charging any fee at all makes a use commercial and so forbidden
    3. The class handout is allowed, the advertising blog is not, and the $20 workshop is unclear, so ask the owner
    4. The class handout and the workshop are allowed, and the advertising blog is unclear because blogs are public
    Show Answer

    The correct answer is C. Nobody earns money from the classroom handout, so it is allowed. Advertising income makes the blog's use commercial, so it is not allowed. Cost recovery is a gray area, so the workshop is unclear and the teacher should ask the owner in writing. NonCommercial is blurrier than it sounds, and the table in the chapter is a guide rather than legal advice. Option B treats every fee as commercial, which overstates the rule.
